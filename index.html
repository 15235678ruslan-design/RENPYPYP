Добавить новую игру

Нужен ZIP из Ren'Py Launcher → Web → Build Web Application.

Данные хранятся локально в браузере.
Важно о совместимости. Запускаются только готовые Ren'Py Web/HTML5 ZIP-сборки, содержащие index.html, файл .wasm и game.zip или .data. Обычные Windows ZIP, исходники .rpy и отдельные .rpa напрямую не запускаются. Некоторые функции Python в Web-версии Ren'Py ограничены.
