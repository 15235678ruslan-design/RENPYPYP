# Ren'Py Player

Веб-приложение для iPhone и других устройств. Импортирует ZIP только из Ren'Py Web / HTML5 build.

## Публикация
Репозиторий настроен на GitHub Pages. Workflow лежит в .github/workflows/pages.yml.
После включения Pages с источником GitHub Actions сайт будет опубликован автоматически после push в main.

URL этого проекта: https://15235678ruslan-design.github.io/RENPYPYP/

## Использование
1. На компьютере открой проект игры в Ren'Py Launcher.
2. Выбери Web → Build Web Application.
3. Перенеси полученный ZIP на iPhone.
4. Открой сайт в Safari и выбери «Добавить ZIP».
5. Добавь сайт на экран «Домой» через меню «Поделиться».

Важно: Windows/Linux/macOS-сборки, исходники .rpy и архивы .rpa не поддерживаются напрямую. Ren'Py Web имеет ограничения платформы браузера. Библиотека хранится локально в IndexedDB браузера.

Для запуска игры Service Worker отдаёт файлы из локальной базы. При первом открытии сайта после публикации может потребоваться однократное обновление страницы.
