# Ren'Py Player — PWA для iPhone и Safari

Это веб-приложение-библиотека для готовых **Ren'Py Web / HTML5** игр. Оно не требует Mac, Xcode, IPA или Sideloadly: сайт открывается в Safari и может быть добавлен на экран «Домой».

## Что умеет эта версия

- Импортирует ZIP-архив готовой Ren'Py Web-сборки.
- Проверяет наличие `index.html`, `.wasm` и `game.zip` / `game.data`.
- Распаковывает файлы на устройстве и сохраняет их в IndexedDB.
- Показывает библиотеку установленных игр.
- Запускает игру в полноэкранной области внутри приложения.
- Пытается разделять `localStorage` и IndexedDB игр, чтобы пользовательские сохранения разных игр не конфликтовали.
- Кэширует оболочку PWA; файлы игр остаются в локальном хранилище браузера.

## Что НЕ запускается

- Обычные Windows / Linux / macOS ZIP-сборки Ren'Py.
- Папки исходного проекта с `.rpy`.
- Отдельные `.rpa` без Web-оболочки.
- Игры, которым обязательны Python-потоки, произвольные сетевые запросы или нативные модули, отсутствующие в Web-порту.

Это ограничение Ren'Py Web / браузерной среды, а не только этого приложения. Для каждой новеллы нужен экспорт Web / HTML5 из Ren'Py Launcher. Даже Web-сборка может не работать на мобильном Safari, если проект использует несовместимые функции, огромные ресурсы или неподдерживаемые браузером аудио/видео форматы.

## 1. Собери Web ZIP игры на Windows

1. Установи Ren'Py SDK на Windows с официального сайта: <https://www.renpy.org/latest.html>.
2. Открой Ren'Py Launcher и выбери нужный проект.
3. Открой раздел **Web (Beta)** / **Web**.
4. Нажми **Build Web Application**.
5. После завершения найди архив `*-web.zip` в папке `имя-проекта-версия-dists`.
6. Перенеси этот ZIP на iPhone (iCloud Drive, OneDrive, кабель или другой удобный способ).

Не перепаковывай игру вручную и не выбирай обычную Windows-сборку.

## 2. Опубликуй плеер бесплатно через GitHub Pages

GitHub Pages нужен потому, что браузер не запускает локальный WebAssembly-проект прямо из ZIP-файла. Web-игра должна открываться с HTTPS-сервера.

1. Создай новый **публичный** репозиторий GitHub, например `renpy-player`.
2. Загрузи в корень репозитория все файлы из этого проекта, включая скрытые `.nojekyll` и `.github/workflows/pages.yml`.
3. В репозитории открой **Settings → Pages**.
4. В разделе **Build and deployment → Source** выбери **GitHub Actions**.
5. Открой вкладку **Actions** и дождись завершения workflow `Deploy Ren'Py Player to GitHub Pages`.
6. GitHub покажет адрес сайта в настройках Pages. Он будет примерно таким: `https://ТВОЙ-ЛОГИН.github.io/renpy-player/`.

Исходный код этого плеера будет публичным вместе с репозиторием. Не добавляй туда личные игры или приватные архивы — библиотека хранится локально в браузере пользователя и не загружается в GitHub.

## 3. Установи на iPhone 12

1. Открой полученный адрес в **Safari** (не во встроенном браузере мессенджера).
2. Нажми **Поделиться**.
3. Выбери **На экран Домой** → **Добавить**.
4. Запусти появившуюся иконку Ren'Py Player.
5. Нажми **Добавить игру** и выбери `*-web.zip` в приложении «Файлы».
6. После импорта нажми **Играть**.

При первом открытии сайт может один раз автоматически перезагрузиться, чтобы включить локальный игровой обработчик Service Worker.

## Совместимость и хранение

- Для импорта ZIP используется Web API `DecompressionStream` с методом `deflate-raw`, который есть в актуальных браузерах. При ошибке обнови iOS/Safari.
- В этой версии установлен лимит: ZIP до 1 ГБ, распакованный объём до 700 МБ, один файл до 600 МБ, не более 20 000 файлов. Фактический объём зависит от свободного места и квоты Safari.
- Импорт и работа с библиотекой должны происходить на HTTPS и не в приватном режиме Safari.
- Не очищай историю и данные сайтов Safari: это может удалить локальную библиотеку и сохранения.
- Веб-порт Ren'Py официально имеет ограничения: нет многопоточности Python; произвольные сетевые запросы блокируются браузерной средой; видео и звук зависят от форматов, поддерживаемых браузером.
- Этот комплект не является нативным IPA и не гарантирует совместимость со всеми играми Ren'Py.

## Структура проекта

- `index.html` — интерфейс приложения.
- `styles.css` — мобильная оболочка и оформление.
- `app.js` — импорт ZIP, проверка архива, каталог игр и запуск.
- `sw.js` — Service Worker: отдаёт распакованные игровые файлы по HTTPS-пути из IndexedDB.
- `manifest.webmanifest` — параметры PWA.
- `.github/workflows/pages.yml` — автоматическая публикация на GitHub Pages.
