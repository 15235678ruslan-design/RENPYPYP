Установи на iPhone

  1. Открой сайт в SafariПосле публикации проекта перейди по адресу сайта именно через Safari.
  2. Нажми «Поделиться»В нижней панели Safari нажми квадрат со стрелкой вверх.
  3. Выбери «На экран Домой»Подтверди добавление. Плеер появится среди приложений.
  4. Добавь Web ZIPВ Ren'Py Launcher на компьютере выбери Web → Build Web Application, затем перенеси полученный ZIP на iPhone.
Совет: не закрывай Safari во время первого импорта большой игры и оставь достаточно свободного места.
